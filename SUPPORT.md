# Support

This is a research artifact maintained by one person. Support is best effort.

| Need | Where |
|---|---|
| How to use the harness | The [documentation site](https://sebasbarrera.github.io/harness-engineering/): greenfield and brownfield guides, CLI, configuration and exit-code references |
| A bug or unexpected behavior | [Open a bug report](https://github.com/SebasBarrera/harness-engineering/issues/new?template=bug.yml) with the version, the command, the exit code and the relevant `harness status` output |
| An idea or improvement | [Open a feature request](https://github.com/SebasBarrera/harness-engineering/issues/new?template=feature.yml) |
| A design decision that affects behavior evaluated in the thesis | [Open a thesis-impact decision](https://github.com/SebasBarrera/harness-engineering/issues/new?template=thesis-impact-decision.yml) |
| A vulnerability or leaked secret | **Do not open an issue**: report it privately as described in [SECURITY.md](SECURITY.md) |

Before opening an issue, check the [known limitations](https://github.com/SebasBarrera/harness-engineering#limitations-and-known-defects)
and the open issues: many behaviors of the research beta are documented defects kept on purpose
(label `thesis-impact`).
