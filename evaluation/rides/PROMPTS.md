Attempts during a lock do not count and do not extend it; when the lock ends the count starts again at 0. A suspended account cannot authenticate.

Only admins may approve, suspend or reactivate (`PermissionError` otherwise); an admin suspending itself raises `ValueError`. A reason made only of spaces counts as empty.

- A7. Courier vehicle is one of `bike`, `moto`, `car`.
- A8. `referral_code(rider_id)` is `REF` followed by the six digits of the rider id (`RID-000007` → `REF000007`). `register_rider(..., referral_code=...)` accepts an existing code of another rider; an unknown code raises `ValueError`.
